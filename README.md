# SoundBoost (by C G Mothish)
Open the SoundBoost folder in Android Studio (Ladybug or newer), let Gradle sync, press Run.
minSdk 29 (Android 10) - targetSdk 37 (Android 17). If SDK 37 is not installed, set compileSdk/targetSdk to 36 in app/build.gradle.kts.
Release build: Build > Generate Signed Bundle/APK.
